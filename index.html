Страницы сайта размещены на GitHub Pages. Профиль, email, дневник, сообщения, оценки и идеи хранятся в Supabase. GitHub Pages не хранит содержимое вашей базы. Email и дневник не показываются другим участникам. Оценки сайта и предложения публичны: любой посетитель, в том числе без регистрации, может видеть имя автора, звёзды, текст и дату; эти записи могут индексироваться поисковиками. Email в них не раскрывается. В чате отображаются имя, город и текст сообщения.

Пароль обрабатывается Supabase Auth, а не сохраняется в файлах сайта. Для сохранения входа браузер хранит токены сессии в localStorage. На общем компьютере выходите из аккаунта. При выполнении чужого JavaScript на странице токены могут быть украдены, поэтому в сайте не используются внешние скрипты.

У участников нет ограничения в 7 дней: чат и дневник бесплатны. Оплат и автоматического продления нет. Бесплатное размещение имеет технические лимиты: база может приостанавливаться при неактивности. Погодный API может ограничивать запросы. При загрузке погоды браузер обращается к публичной погодной функции Supabase без email и токенов аккаунта. Supabase получает IP браузера, а Open-Meteo — запрос сервера с координатами центра выбранного города, без IP посетителя и данных аккаунта. Постоянная доступность не гарантируется.

Удалить аккаунт вместе со своими сообщениями, уловами, оценкой и идеями или выгрузить собственные данные можно в профиле. Подтверждение почты включается в Supabase Auth. Восстановление пароля через этот интерфейс пока не реализовано. Владелец сайта может удалять сообщения, оценки и идеи и блокировать участников. Суммарная оценка считается по оставшимся опубликованным оценкам, не по удалённым. Самостоятельно удалить отдельную оценку или идею нельзя: обратитесь к владельцу либо удалите аккаунт вместе со всеми своими записями. Блокировка не удаляет аккаунт и не закрывает доступ к собственным данным для выгрузки и удаления. Не используйте важный пароль.

Выбранный город, рыба, тема и временный погодный кэш сохраняются в localStorage браузера. Для удаления этих локальных настроек используйте очистку данных сайта в браузере.

Перед публичным запуском владелец должен указать свои реквизиты и контакты, утвердить политику обработки данных и настроить HTTPS. Эта страница — описание тестовой версии, не юридическая политика.
